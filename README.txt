ATTENDIFY - STUDENT ATTENDANCE SYSTEM

HOW TO RUN:
1. Extract the ZIP file.
2. Open the extracted "attendify" folder.
3. Double-click index.html.
4. The website will open in Chrome/Edge.

FEATURES:
- Dashboard
- Student management
- Add/Edit/Delete students
- Section management
- Add/Edit/Delete sections
- Attendance: Present, Absent, Late
- Select attendance date
- Attendance history
- Reports and print
- Teacher name settings
- Export JSON backup
- Reset data
- Data automatically saved in browser localStorage

NO SERVER OR DATABASE IS REQUIRED.
This version is a complete front-end application and works offline.
